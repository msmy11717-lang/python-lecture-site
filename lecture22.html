LECTURE 22

Claude CodeとGitの連携

第18〜21回の統合。Claude CodeがGitを自動操作する仕組みを理解し、日本語指示でadd・commit・pushまで任せる実践的な使い方と全操作まとめを習得する。

Claude CodeはGitを自動操作できる
Claude CodeはAIエージェントとして動くため、Gitコマンドもツールとして自律的に実行できます。「ファイルを変更してコミットして」と日本語で指示するだけで、add・commit・pushまで自動で処理します。
  • git add・git commit・git push をClaude Codeが代わりに実行する
  • コミットメッセージも文脈から自動生成する（日本語での指定も可）
  • ブランチの作成・切り替え・マージも指示できる
  • 危険な操作（force push等）は事前に確認を求める（安全設計）
日本語指示でadd・commit・pushまで任せる
Claude Codeへの日本語指示例
【指示例①：コミットだけ】 「今の変更をコミットして。メッセージは『lecture22.htmlを追加』で」 → Claude Codeが実行するコマンド： git add lecture22.html git commit -m "lecture22.htmlを追加" 【指示例②：GitHubまで一気に】 「今の変更をコミットしてGitHubにpushして」 → Claude Codeが実行するコマンド： git add . git commit -m "変更内容を自動要約したメッセージ" git push origin main 【指示例③：履歴確認】 「最近のコミット履歴を見せて」 → Claude Codeが実行するコマンド： git log --oneline
git log --oneline で履歴を確認する
コミット履歴はこのコマンドで確認するのが最もシンプルです。Claude Codeに「git log を確認して」と伝えると、自動で実行して結果を教えてくれます。
ターミナル（履歴確認）
# 1行ずつコンパクトに履歴を表示 git log --oneline # 出力例： e697081 lecture22.htmlを追加 6d4aaf6 ブランチ上でメモを追加 cca65dc 2回目のメモを追加 5102be4 最初のメモを追加
