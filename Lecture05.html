LECTURE 05

Claude API呼び出し

AnthropicのAPIキー取得・anthropicライブラリでClaudeを実際に呼び出す。f文字列・辞書も習得。

APIキーとは
Claudeのシステムに入るための「あなた専用のパスワード」です。console.anthropic.comで取得します。漏れると他人があなたのキーで使い放題になるため絶対に公開しないでください。
  • console.anthropic.com でAPIキーを発行
  • sk-ant- から始まる文字列
  • 画面を閉じると二度と見られないので必ずコピー保存
  • Billing → Usage limits で月額上限を設定（推奨：$5〜$10）
Claude呼び出しの基本コード
python
import anthropic
import httpx

http_client = httpx.Client(verify=False)
client = anthropic.Anthropic(
    api_key="sk-ant-ここに貼る",
    http_client=http_client
)

def ask_claude(question):
    message = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=1000,
        messages=[{"role": "user", "content": question}]
    )
    return message.content[0].text

answer = ask_claude("Pythonとは何か3行で説明してください")
print(answer)
