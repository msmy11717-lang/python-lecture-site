LECTURE 08

定期実行

scheduleライブラリとwhile Trueで定期実行を実装。Windowsタスクスケジューラで自動起動も設定。

スケジューリングとは
今まではコードを手動実行するだけでしたが、スケジューリングを使うと指定したタイミングで自動実行できます。
  • schedule.every().day.at('09:00').do(関数) → 毎日9時
  • schedule.every(10).minutes.do(関数) → 10分おき
  • while True + time.sleep(1) → 永遠にループ
  • Ctrl+C → 停止
毎朝Claudeに質問して保存するコード
python
import schedule, time

def morning_task():
    print("朝のタスク開始")
    # Claudeへの質問・CSV保存の処理をここに書く

schedule.every().day.at("09:00").do(morning_task)

morning_task()  # 動作確認用

while True:
    schedule.run_pending()
    time.sleep(1)
実行結果
朝のタスク開始
