LECTURE 14

AIエージェントの構造

ループ・ツール・状態管理の3要素でAIエージェントの仕組みを理解する。Claude Codeが内部でやっていることを解剖する。

エージェントとは何か
通常のLLM呼び出しは「1回の質問→1回の回答」で終わります。エージェントは「目標を与えると、複数回のLLM呼び出しと外部ツールの使用を自律的に繰り返して、目標を達成しようとする仕組み」です。Claude Codeはまさにこれです。
  • 通常のLLM：質問 → 回答（1往復で終了）
  • エージェント：目標 → 思考 → 行動 → 観察 → 思考 → …→ 完了（ループ）
  • 「行動」にはツール（ファイル読み書き・コード実行・検索など）を使う
  • Claude Codeはファイル読み込み・コード実行・修正のループを自動で回す
エージェントの基本ループ（ReActパターン）
エージェントの代表的なパターンが「ReAct（Reasoning + Acting）」です。思考して行動し、結果を観察してまた思考する、このループが自律動作の核心です。
概念（ループの構造）
目標：「data.csvを読んでClaudeに分析させて結果をresult.txtに保存する」

ループ1：
  思考 → 「まずdata.csvを読む必要がある」
  行動 → ツール呼び出し：READ_FILE(data.csv)
  観察 → ファイルの内容を取得

ループ2：
  思考 → 「内容をClaudeに分析させる」
  行動 → LLM呼び出し（データ＋分析指示）
  観察 → Claudeの分析結果を取得

ループ3：
  思考 → 「結果をファイルに保存する」
  行動 → ツール呼び出し：WRITE_FILE(result.txt, 分析結果)
  観察 → 保存完了

→ 目標達成。ループ終了
状態管理：会話履歴をリストで保持する
エージェントが複数回LLMを呼び出すとき、LLMは前の会話を覚えていません。プログラム側でmessagesリストを保持し、毎回すべての履歴を渡すことで「記憶」を実現します。
python
import anthropic

client = anthropic.Anthropic(api_key="sk-ant-ここに貼る")

# 状態（会話履歴）をリストで管理する
messages = []

def chat(user_input):
    # ユーザーの発言を履歴に追加
    messages.append({"role": "user", "content": user_input})

    # 履歴ごとLLMに渡す
    response = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=500,
        system="あなたは親切なPythonアシスタントです。",
        messages=messages  # ← 全履歴を渡す
    )

    ai_reply = response.content[0].text

    # AIの返答も履歴に追加（次回の文脈になる）
    messages.append({"role": "assistant", "content": ai_reply})

    return ai_reply

# 多ターン会話
print(chat("変数とは何ですか？"))
print(chat("それを使う例を教えてください"))  # 前の文脈を覚えている
print(chat("もっと複雑な例も見せてください"))  # 文脈が積み上がっている
実行イメージ
変数とはデータに名前をつけて保存する箱のようなものです... 先ほどの変数の例として：name = "田中" のように書きます... もっと複雑な例として辞書型変数があります：person = {"name": "田中", "age": 47}...
ツールとは何か
エージェントが「行動」するためには「手」が必要です。これがツールです。LLMはツールを呼び出すことで、外部世界（ファイル・Web・コード実行環境など）と連携できます。
  • ファイル読み書き → os / open() で実装（第6・7回で学習済み）
  • コード実行 → subprocess で実装（コードを実行して結果を取得）
  • Web検索 → requests で実装（第9回で学習済み）
  • Claude API → anthropic ライブラリで実装（第5回で学習済み）
  • Claude CodeはこれらすべてのツールをAIが自律的に使っている
シンプルなエージェント実装
python
import anthropic, os client = anthropic.Anthropic(api_key="sk-ant-ここに貼る") def read_file_tool(filename): """ツール：ファイルを読む""" if os.path.exists(filename): with open(filename, "r", encoding="utf-8") as f: return f.read() return f"エラー：{filename} が見つかりません" def simple_agent(goal): messages = [{"role": "user", "content": goal}] for step in range(5): # 最大5ループ response = client.messages.create( model="claude-haiku-4-5-20251001", max_tokens=500, system="目標達成のために必要なら READ_FILE:ファイル名 と書いてください。" "完了したら DONE: と書いて結果を示してください。", messages=messages ) reply = response.content[0].text messages.append({"role": "assistant", "content": reply}) print(f"[Step {step+1}] {reply[:80]}...") # ツール呼び出しを検出 if "READ_FILE:" in reply: filename = reply.split("READ_FILE:")[1].split()[0] content = read_file_tool(filename) messages.append({"role": "user", "content": f"ファイルの内容:\n{content}"}) # 完了を検出 if "DONE:" in reply: print("エージェント完了") break simple_agent("data.csvというファイルがあれば読んで内容を要約してください")
