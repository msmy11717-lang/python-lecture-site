LECTURE 09

Webスクレイピング

requests・BeautifulSoupでWebから情報を自動収集する概念と構造を習得。SSL環境問題にも対処。

スクレイピングとは
Webサイトから情報を自動で取ってくる技術です。人間がブラウザで手動コピーする作業を自動化します。
  • requests.get(url) → HTMLを取得
  • BeautifulSoup → HTMLを解析して必要部分を抽出
  • find() → 最初の1件
  • find_all() → 全件をリストで取得
  • verify=False → SSL検証を無効（環境問題の対処）
基本構造
python
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
headers = {"User-Agent": "Mozilla/5.0"}
response = requests.get(url, headers=headers, verify=False)

soup = BeautifulSoup(response.text, "html.parser")
titles = soup.find_all("h2")

for title in titles:
    print(title.text.strip())
SSL問題について
Windowsのネットワークフィルタドライバが原因でSSL通信がブロックされる場合があります。feedparser等の代替手段を使うか、別環境での実行を検討してください。
