LECTURE 03

基本文法

変数・リスト・繰り返し・条件分岐の4つを習得。自動化コードの8割はこの4つで書ける。

① 変数
データに名前をつけて保存する箱。付箋メモのようなイメージです。
python
name = "田中誠"
age = 47
print(name)
print(age)
実行結果
田中誠 47
② リスト
複数のデータをまとめる入れ物。番号は0から始まります。
python
files = ["report.pdf", "data.xlsx", "photo.jpg"]
print(files[0])
print(files[1])
実行結果
report.pdf data.xlsx
③ 繰り返し
リストの中身を1つずつ取り出して同じ処理を繰り返す。これが自動化の核心です。
python
files = ["report.pdf", "data.xlsx", "photo.jpg"]
for file in files:
    print(file + " を処理中...")
実行結果
report.pdf を処理中... data.xlsx を処理中... photo.jpg を処理中...
④ 条件分岐
状況によって処理を自動で切り替える。信号機のようなイメージ。
python
score = 85
if score >= 70:
    print("高評価")
elif score >= 50:
    print("中評価")
else:
    print("低評価")
実行結果
高評価
