LECTURE 04

関数とライブラリ

処理をまとめて再利用できる関数の作り方と、pip installでライブラリを追加する方法を学ぶ。

① 関数
複数の命令をひとまとめにして名前をつけたもの。洗濯機のスタートボタンのように「ボタン1つで全部動く」イメージです。
python
def show_result(name, score):
    if score >= 70:
        print(name + "：合格")
    else:
        print(name + "：不合格")

show_result("田中誠", 85)
show_result("山田健太", 42)
実行結果
田中誠：合格 山田健太：不合格
② ライブラリ
他の人が作った便利な部品集。pip installでインストールしてimportで使います。
  • pip install ライブラリ名 → ターミナルで1回だけ実行
  • import ライブラリ名 → コードの冒頭に毎回書く
  • openpyxl → Excelの読み書き
  • anthropic → Claude AIを呼び出す
  • requests → WebへのアクセスとAPI呼び出し
確認課題
✓ この講義の課題

  • pip install anthropic を実行してインストールを確認する
