LECTURE 12

LLMは何をしているのか

トークン・確率・予測の3つのキーワードでLLMの内部動作を理解する。「AIが考えている」という誤解を解く。

LLMの正体
LLM（Large Language Model）とは「大規模言語モデル」の略です。Claudeも ChatGPT も、すべてLLMです。その正体は「次のトークンを予測する確率機械」です。人間のように「考えて」答えているわけではありません。
  • LLM = Large Language Model（大規模言語モデル）
  • 膨大なテキストデータを学習して「次の言葉の確率」を覚えたもの
  • Claudeも GPT-4 も、基本構造は同じ「確率予測エンジン」
  • 「理解して答えている」のではなく「確率的に最適な続きを生成している」
トークンとは何か
LLMはテキストを「トークン」という単位で処理します。トークンは単語や文字の断片で、日本語は英語より多くのトークンを消費します。APIのコストはトークン数で計算されます。
  • 英語：「Hello World」→ ["Hello", " World"]（2トークン前後）
  • 日本語：「こんにちは」→ ["こん", "にち", "は"]（3〜5トークン前後）
  • 1トークン ≈ 英語0.75単語 ≈ 日本語0.5文字（目安）
  • max_tokens でAPIの最大出力トークン数を制限できる
  • 課金はinput tokens + output tokensの合計で計算される
確率による予測の仕組み
LLMは「これまでの文脈から次に来る可能性が高いトークンを選ぶ」ことを繰り返します。「今日の天気は」という入力に対して、確率分布から次のトークンを選びます。
概念コード（疑似コード）
# LLMの内部動作イメージ（実際のコードではありません）

入力 = "今日の天気は"

次のトークンの確率分布:
  "晴れ"    → 38%
  "くもり"  → 27%
  "雨"      → 19%
  "雪"      → 8%
  "不明"    → 8%

→ 確率に従って"晴れ"を選択

次の入力 = "今日の天気は晴れ"
→ また次のトークンを予測...これを繰り返す
temperatureパラメータ
temperatureは確率分布の「ランダム性」を制御するパラメータです。0に近いほど確定的・一貫した回答になり、1以上では創造的・多様な回答になります。用途に応じて使い分けます。
python
import anthropic

client = anthropic.Anthropic(api_key="sk-ant-ここに貼る")

# temperature=0：決定論的・一貫した回答（事実確認・分類に向く）
response_stable = client.messages.create(
    model="claude-haiku-4-5-20251001",
    max_tokens=200,
    temperature=0,
    messages=[{"role": "user", "content": "Pythonとは何か1行で"}]
)

# temperature=1：創造的・多様な回答（ブレスト・文章生成に向く）
response_creative = client.messages.create(
    model="claude-haiku-4-5-20251001",
    max_tokens=200,
    temperature=1,
    messages=[{"role": "user", "content": "Pythonとは何か1行で"}]
)

print("安定版:", response_stable.content[0].text)
print("創造版:", response_creative.content[0].text)
  • temperature=0 → 毎回ほぼ同じ回答（分類・要約・コード生成）
  • temperature=0.5〜0.7 → バランス型（一般的な対話）
  • temperature=1以上 → ランダム性高い（創作・アイデア出し）
  • デフォルト値はモデルによって異なる（Claudeは概ね1.0）
誰も「考えて」いない
LLMは意味を「理解」して答えているのではありません。学習データのパターンを元に、文脈に合う確率が高いトークン列を生成しているだけです。これがハルシネーション（第16回）の根本原因であり、プロンプト設計（第13回）が重要な理由でもあります。
  • LLMに「意図」も「理解」も「常識」もない
  • あるのは「学習データから抽出した統計的パターン」だけ
  • それでも非常に優秀なのは、学習データが膨大だから
  • 限界を知ることが、AIを正しく使う第一歩
